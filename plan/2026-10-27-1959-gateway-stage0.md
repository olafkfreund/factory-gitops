# Plan: model gateway stage 0

- Two PRs, merged in order: PR 1 widens Kyverno scope to namespace `gateway`;
  PR 2 adds the `model-gateway` Argo app. PR 2 merges only after the live
  `verify-aifactory-signature` rule lists `gateway`.
- Own Argo Application `apps/model-gateway`, namespace `gateway`,
  `CreateNamespace=true`, prune + selfHeal. Not the `aifactory` kustomization.
- Image `ghcr.io/olafkfreund/aifactory:v3.10.12-gateway@sha256:17de698aeca67c11c1f6c2d678353162bcfbb97b9971a868547435b310c3232a`

  `release.yml@refs/heads/main` (cosign verified 2026-10-27).

  `factory` on TCP 8080; egress to kube-dns UDP/TCP 53 only.
