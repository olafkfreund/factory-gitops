# Spec: model gateway stage 0

## Design

Two PRs, merged in order, because the policy must be live before the Pod is
admitted.

**PR 1 — admission scope** (`apps/kyverno-policies/manifests/`):

- `verify-factory-image-signatures.yaml`, rule `verify-aifactory-signature`:
  `namespaces: [factory]` → `[factory, gateway]`. Same glob, same attestor
  (`(deploy|release|build-nix).yml@refs/heads/main`). The fides rule is the
  precedent for a rule matching a non-`factory` namespace.
- `require-first-party-signature-coverage.yaml`: `namespaces: [factory]` →
  `[factory, gateway]`, so an uncovered first-party image in `gateway` is
  reported rather than silent. Audit, no registry calls.

**PR 2 — the app** (`apps/model-gateway/`, own Argo Application, picked up by
the root app-of-apps; not the `aifactory` kustomization):

- `application.yaml`: path `apps/model-gateway/manifests`, destination
  namespace `gateway`, automated prune + selfHeal, `CreateNamespace=true`.
- Deployment `model-gateway`, 2 replicas:
  - image `ghcr.io/olafkfreund/aifactory:v3.10.12-gateway@sha256:17de698aeca67c11c1f6c2d678353162bcfbb97b9971a868547435b310c3232a`.
    Tag **and** digest: the Kyverno glob `aifactory:*` does not match a bare
    `aifactory@sha256:` reference (see the coverage policy's comment), and the
    digest makes the bytes immutable.
  - no env (unconfigured: the gateway returns 503 on chat until
    `GATEWAY_UPSTREAM_URL` and `GATEWAY_CLIENT_TOKEN` are set); port 8080.
  - pod: `runAsNonRoot`, `runAsUser: 65532`, seccomp `RuntimeDefault`,
    `automountServiceAccountToken: false`; container:
    `readOnlyRootFilesystem`, no privilege escalation, drop ALL.
  - requests 10m/32Mi, limits 200m/128Mi (stdlib Python).
  - readiness and liveness `GET /healthz`. `/healthz` is 200 while the gateway
    correctly refuses chat, so liveness tells "refusing" from "dead".
- Service `model-gateway`, ClusterIP, 8080.
- PDB `minAvailable: 1` (2 replicas, so a drain can proceed).
- NetworkPolicies: `default-deny` (all Pods, Ingress + Egress);
  `allow-ingress-from-factory` (namespace `factory` → TCP 8080);
  `allow-egress-dns` (→ kube-system kube-dns, UDP/TCP 53). No upstream egress:
  none is configured. Stage 1 adds exactly one upstream rule when it
  configures one.

## Alternatives rejected

- **Deploy into `factory`**: no policy change needed, but the task asks for a
  `gateway` namespace and the epic wants the gateway isolated from task Pods.
- **One PR**: Argo syncs Applications independently; if `model-gateway`
  syncs before `kyverno-policies`, the Pod is admitted unverified and the
  admission evidence is lost.
- **Digest-only image reference**: no Kyverno glob matches it — admitted
  unverified.
- **Inside the `aifactory` kustomization**: AIFactory's CD repoints every
  `aifactory=` image there.
- **Egress to Ollama/an upstream now**: nothing is configured; an open rule
  with no user is attack surface.

## Risks

- Editing the enforcing policy invalidates Kyverno's verify cache once
  (bounded extra Rekor calls), and a mistaken edit could affect `factory`.
  Mitigation: only the namespace list changes; `manifest-validate` runs the
  Kyverno scope tests; `./PANIC.sh 1` is the documented back-out.
- kube-router NetworkPolicy blocking kubelet probes → Pods never Ready.
  Kubernetes exempts node-originated traffic; checked after sync, revert if not.
- Read-only rootfs: Python cannot write `__pycache__`; it tolerates this.

## Verification

- `cosign verify` of the digest with Kyverno's issuer and subject regexp
  (done: release.yml@refs/heads/main, commit ec354c0).
- CI `manifest-validate` green on both PRs.
- After PR 1 syncs: live rule lists `gateway`.
- After PR 2 syncs: Pods Ready, 0 restarts; `kubectl get polr -n gateway`
  shows a `pass` for `verify-aifactory-signature`; `/healthz` 200 and chat
  POST 503 from inside the cluster.
- Server-side dry-run of a Pod in `gateway` using an unsigned `aifactory:*`
  reference (`aifactory:sha256-cec9…f14d.att`, `cosign verify`: no signatures
  found) is denied by `verify-aifactory-signature`; nothing is created.
